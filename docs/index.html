Trocas & Comunidade
Isolado

Arquitetura de Alta Performance

Criado Especificamente para Jogadores de Idle Games

Multi-Telas Dinâmico

Comece com 1 janela e adicione novas telas com 1 clique no botão + Janela. A grade se ajusta automaticamente para 2, 3, 4 ou mais janelas simultâneas.

Modo Ultra Leve (Economia de CPU/GPU)

Desativa transições e efeitos CSS supérfluos dos jogos, reduzindo a carga no processador e placa de vídeo para que você possa farmar sem travar suas outras tarefas.

Sessões 100% Isoladas por Aba

Cada aba do 4Nav opera como uma partição isolada com seu próprio pote de cookies e logins. Entre com contas diferentes do mesmo jogo ou de redes sociais sem conflitos.

Atalhos de Maximizar Instantâneo

Pressione Alt + 1, Alt + 2 para expandir uma tela para 100% da visão e cuidar daquela conta. Pressione ESC para restaurar o grid.

Mutação Inteligente de Áudio

Muta automaticamente o áudio das telas que não estiverem em foco. A Web Audio API pode gastar até 25% da CPU quando vários jogos rodam áudio ao mesmo tempo.

Liberador de Memória RAM

Botão integrado com 1 clique para limpar caches estáticos e disparar a coleta de lixo da memória, garantindo estabilidade mesmo em farms contínuos de 24 horas.

Instalação Simples

Como Usar o 4Nav

1

Baixe o Executável

Acesse a seção de Releases no repositório GitHub e baixe a versão compilada para Windows (ou clone o repositório se preferir compilar localmente).

2

Abra o Navegador

Dê dois cliques em 4Nav.exe ou execute o arquivo Abrir 4Nav.bat.

3

Adicione suas Contas & Jogue

Clique em + Janela para abrir quantas telas quiser e comece seu farm em múltiplas instâncias!
